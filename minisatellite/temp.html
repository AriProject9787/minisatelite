WIRELESS VIA ESP32-CAM

Arduino Uno transmits 4x DHT22 telemetry via Pin 11 to ESP32-CAM U0R (GPIO 3). ESP32-CAM serves data over Wi-Fi at /data and live OV2640 camera feed at /cam or /stream.

DIRECT USB GROUND LINK

Plug Arduino Uno directly into PC via USB. Click CONNECT ARDUINO (USB) in this dashboard to receive 4-sensor DHT22 packets directly via Web Serial API.

    DHT22 PINOUT (Looking at front grill with pins pointing downward):
    * Pin 1 (Left):  VCC -> Connect to Arduino +5V (or +3.3V)
    * Pin 2:         DATA -> Connect to Digital Pin (D2 / D3 / D4 / D5)
                     (If bare 4-pin DHT22, place 4.7kΩ to 10kΩ resistor between Pin 1 and Pin 2)
                     (If 3-pin breakout module, pull-up resistor is already built-in!)
    * Pin 3:         NC   -> Leave unconnected (Null)
    * Pin 4 (Right): GND  -> Connect to Arduino GND

    |                    |       COMMON GROUND         |                    |
    +--------------------+                             +--------------------+

    CRITICAL LEVEL SHIFTING NOTE:
    * Arduino Uno digital pins output 5V. ESP32-CAM GPIOs are strictly 3.3V rated.
    * The 1kΩ / 2kΩ voltage divider reduces Arduino TX (5V) down to ~3.33V:
      Vout = 5.0V * (2kΩ / (1kΩ + 2kΩ)) = 3.33V (Safe for ESP32 U0R).
    * ESP32-CAM TX outputs 3.3V, which connects directly to Arduino Uno Pin 10 (RX).
    * Arduino GND and ESP32-CAM GND MUST be connected together!
